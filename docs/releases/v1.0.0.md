Первая версия Price List Merger: свод прайс-листов поставщиков в один Excel.

**Что внутри**
- Чтение `.xlsx`, `.xlsm` и `.csv` (UTF-8 и Windows-1251, любой разделитель), поиск строки-заголовка и листа с таблицей.
- Автоподбор колонок и профили поставщиков.
- Очистка цен и артикулов, отчёт об отброшенных строках.
- Сопоставление товаров по артикулу, названию и похожему названию.
- Наценка ступенями и округление цены продажи.
- Итоговый Excel из пяти листов с подсветкой лучшей цены.
- Консольная версия `PriceListMerger-cli.exe` для планировщика задач.
- Демо-прайсы трёх вымышленных поставщиков в папке `demo`.

**Файлы**
- `PriceListMerger-1.0.0-Setup.exe` — установщик (права администратора не нужны).
- `PriceListMerger-1.0.0-portable.zip` — переносная версия.

Windows 10/11, 64 бит.
