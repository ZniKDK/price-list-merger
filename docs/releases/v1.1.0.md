Обновление оформления.

**Что нового**
- Светлая и тёмная тема. По умолчанию — как в Windows, программа переключается вместе с системой. Выбор — внизу боковой панели.
- Боковая панель вместо верхнего меню: шаги мастера, тема, папка профилей поставщиков, «О программе».
- Единый стиль полей, выпадающих списков, галочек, ползунка и полос прокрутки в обеих темах.
- Таблицы: плавная прокрутка, разделители столбцов, полный текст обрезанной ячейки во всплывающей подсказке, подсказка на пустой таблице («Ничего не найдено», «Отброшенных строк нет»).
- Плавная смена шагов, раскрытие списков, «досчитывающие» цифры итогов.
- После сохранения Excel — уведомление с кнопкой «Открыть».
- В списке прайсов — имя файла, полный путь во всплывающей подсказке.

**Файлы**
- `PriceListMerger-1.1.0-Setup.exe` — установщик (права администратора не нужны).
- `PriceListMerger-1.1.0-portable.zip` — переносная версия.

Windows 10/11, 64 бит.
